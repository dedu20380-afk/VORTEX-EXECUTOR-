# VORTEX Mobile - projeto unificado

Este projeto une a base do TK Executor com o launcher/overlay do Vortex Mobile.

## Incluído
- Interface Android em Jetpack Compose.
- Nome e identidade VORTEX.
- Editor de Lua/Luau.
- Biblioteca local de scripts.
- Console.
- Botões de salvar/carregar/limpar.
- Botão para abrir o Roblox instalado.
- Permissão e ícone flutuante VORTEX.
- Ícone flutuante arrastável.
- Configurações básicas.
- Build Android configurado para APK.

## Build no Replit
Importe este projeto como um repositório/projeto Android e peça:

"Compile este projeto Android como APK instalável. Preserve namespace, applicationId, versão, dependências Compose, interface VORTEX, editor, biblioteca, launcher do Roblox e overlay. Corrija somente erros de compilação ou configuração necessários para gerar o APK. Não substitua a arquitetura por HTML."

## Limitação
O botão "Testar" registra o código no console, mas não injeta nem executa scripts dentro do cliente Roblox. O overlay é somente um painel auxiliar do Android.
